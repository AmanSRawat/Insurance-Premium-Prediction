# Insurance Premium Prediction

A full-stack machine learning web application that predicts medical insurance premiums from user inputs (age, weight, height, smoking status, region, sex, number of children). A scikit-learn model trained in a Jupyter notebook is served by a FastAPI backend and consumed by a React (Vite + Tailwind CSS) frontend.

## Architecture

```
┌─────────────────┐   HTTP POST /predict     ┌──────────────────┐
│  React (Vite)   │ ───────────────────────▶ │   FastAPI        │
│  localhost:5173 │ ◀─────────────────────── │   localhost:8000 │
└─────────────────┘    JSON prediction       └────────┬─────────┘
                                                      │ pickle.load
                                                      ▼
                                              ┌────────────────┐
                                              │  model.pkl     │
                                              │  (sklearn)     │
                                              └────────────────┘
```

1. User fills the form on the React frontend.
2. The frontend POSTs the input as JSON to `http://localhost:8000/predict`.
3. FastAPI validates the payload via Pydantic, computes BMI from weight & height, builds a one-row DataFrame, and runs the trained scikit-learn model.
4. The backend returns a JSON object with the predicted premium; the frontend displays it to the user.

## Data Contract

The frontend sends the following JSON body to `POST /predict`:

| Field | Type | Validation |
|---|---|---|
| `age` | int | `0 < age < 120` |
| `weight` | float | `weight > 0` (kg) |
| `height` | float | `0 < height < 2.5` (meters) |
| `smoker` | bool | required |
| `region` | string | one of `southwest`, `southeast`, `northwest`, `northeast` |
| `sex` | string | one of `male`, `female` |
| `children` | int | `>= 0` |

The backend derives `bmi` server-side as `weight / height²`, so the frontend never needs to send it.

**Response:**
```json
{
  "Predicted Insurance": 12345.67
}
```

## Getting Started

### Prerequisites
- Python 3.10 or newer
- Node.js 18+ and npm
- A trained `model.pkl` (regenerate by running `backend/model.ipynb` if not present)

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd Insurance-Premium-Prediction
```

### 2. Set up the backend
```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
# source .venv/bin/activate

pip install -r requirements.txt
```

#### Generate `model.pkl`
The trained model artifact is gitignored. Run the notebook to (re)generate it:

```bash
jupyter notebook model.ipynb
```

Run all cells — the final cell should save `model.pkl` into the `backend/` directory.

#### Start the API
```bash
uvicorn main:app --reload
```

The backend will be available at `http://localhost:8000`.

Interactive API docs: `http://localhost:8000/docs`.

### 3. Set up the frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

The frontend will be available at `http://localhost:5173`.

## Usage

1. Open `http://localhost:5173` in a browser.
2. Fill in the form: age, weight (kg), height (m), smoker (yes/no), region, sex, children.
3. Click **Predict Premium**.
4. The predicted insurance premium is displayed.

## Configuration

For local development the defaults are hard-coded and work out of the box:
- Frontend → `http://localhost:8000/predict` (see `frontend/src/component/InputForm.jsx`)
- Backend CORS → `http://localhost:5173` (see `backend/main.py`)

If you deploy, update these URLs accordingly.

## Notes

- `model.pkl` is intentionally gitignored. The notebook is the source of truth for the model.
- CORS is configured for the Vite dev origin only. Update `allow_origins` in `backend/main.py` for production deployments.
- The frontend currently uses `fetch` (not `axios`) to call the API, despite `axios` being listed as a dependency.
